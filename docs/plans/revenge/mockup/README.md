# Revenge UI mock-up

The source of the mock-up canvas, version 7 (id `1795626982-9e53`, 2026-11-25), which applies the
user's six review comments on version 6. The live canvas is a private claude.ai design artifact:
https://claude.ai/artifact/9M4d6XpfKVF8XftFNd8Ncs (only its owner can open it unless shared).
These files are a record and don't render on their own.

| Board | File | Shows |
|---|---|---|
| Tooltip | `Main.dc.html` | The one skull line, "(5) You, Mira, Tavish, +1 more", and the same tooltip with Shift held, listing each kill |
| Nameplate mark | `Nameplates.dc.html` | The skull beside the game's own nameplate and beside a nameplate addon's plate, both left unchanged |
| Settings | `Settings.dc.html` | Options › AddOns › Revenge, with working controls, the modifier choice, the popup option and add-by-name |
| Alerts | `Alerts.dc.html` | The silent popup and the chat lines for "killer nearby" and "friend or guildmate killed" |
| Map pins | `MapPins.dc.html` | Skull pins coloured for you, friends and guildmates; a pin's hover details; the right-click "Dismiss kill" menu |

All names, guilds and kills are made up.
